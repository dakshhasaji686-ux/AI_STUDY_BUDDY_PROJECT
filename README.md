## Project Overview
AI Study Buddy is an AI-powered learning assistant built using Python and Streamlit. It helps students understand topics and prepare for interviews and exams.

## Features
- Topic explanations from beginner to advanced level.
- Easy, Medium, and Hard difficulty levels.
- Technical interview questions.
- Behavioral questions.
- Coding questions.
- AI-powered interactive chat.

## Technologies Used
- Python
- Streamlit
- Google Gemini / AI Agent
- Google Search API
- Python Libraries

## How to Run

1. Clone the repository.
2. Install the required libraries:

```bash
pip install -r requirements.txt
```

3. Run the application:

```bash
streamlit run ai_studybuddy_project.py
```

4. Open the local URL in your browser.

## Project Purpose
To make learning easier and help students improve their technical knowledge and interview preparation using AI.
